Architectural Overview

Engineered for professional ROM development on Windows

Tenkai ROM Studio organizes complex low-level operations into a clean, tabbed workflow. Built natively for Windows x64 with a completely self-contained portable toolchain.

Visión Arquitectónica

Diseñado para desarrollo profesional de ROMs en Windows

Tenkai ROM Studio organiza complejas operaciones de bajo nivel en un flujo limpio por pestañas. Construida de forma nativa para Windows x64 con una cadena de herramientas portable y autocontenida.

1. USB Device & FEL Flasher

1. Dispositivo USB y Flasheo FEL

Real-time detection of Allwinner devices in FEL mode (VID 1F3A, PID EFE8), FES, and ADB. Includes SoC ID verification before flashing to prevent hardware mismatch, plus integrated Zadig driver management.

Detección en tiempo real de dispositivos Allwinner en modo FEL (VID 1F3A, PID EFE8), FES y ADB. Verificación estricta de SoC ID antes de flashear para evitar incompatibilidades de hardware y gestor de drivers Zadig.

2. Linear 5-Step ROM Pipeline

2. Flujo de Creación en 5 Pasos

Streamlined pipeline: 1. Extract IMAGEWTY to workspace with manifest, 2. Root/Patch boot with Magisk (arm64 auto-detect), 3. Optional Logo customization, 4. Full Repack with recalculating checksums, 5. Direct Flashing.

Flujo estructurado: 1. Extraer IMAGEWTY a workspace con manifiesto, 2. Root/Parchar boot con Magisk (autodetección arm64), 3. Logos de inicio opcionales, 4. Reempaque recalculando checksums, 5. Flasheo directo.

3. Quick Logo Patcher

3. Pestaña Rápida de Logos

Dedicated tool to inject custom boot logos (1920x1080) and fastboot graphics (257x246) into existing ROMs in seconds without having to unpack gigabytes of dynamic partitions.

Herramienta dedicada para inyectar logotipos de inicio (1920x1080) y gráficos fastboot (257x246) en ROMs existentes en segundos sin desempaquetar gigabytes de particiones dinámicas.

4. Deep Inspection & ROM Diff

4. Inspección y Comparador Diff

Deep header audit for IMAGEWTY containers (fes1, u-boot, boot, super), SHA-256 integrity hashing, Kernel ELF architecture inspection, and differential comparison between stock and custom ROMs.

Auditoría profunda de cabeceras IMAGEWTY (fes1, u-boot, boot, super), cálculo de hash SHA-256, inspección de Kernel ELF y reporte diferencial entre la ROM oficial de fábrica y la modificada.

Step-by-Step Pipeline

How the 5-step creation pipeline works

Standardized, safe, and reproducible workflow for building custom firmware distributions on Windows.

Flujo de Creación

Cómo funciona el proceso ordenado de 5 pasos

Flujo estandarizado, seguro y reproducible para crear distribuciones de firmware personalizadas en Windows.

01

Extract ROM to Workspace

Extraer ROM a Workspace

Unpacks the entire IMAGEWTY container into Workspaces/, generating a safe _tenkai_imagewty_manifest.json and enabling Windows Explorer file inspection.

Desempaqueta el contenedor IMAGEWTY en Workspaces/, generando el manifiesto _tenkai_imagewty_manifest.json y permitiendo explorar los archivos en Windows.

02

ROOT & Magisk Patching

ROOT y Parcheo con Magisk

Automatically detects the Kernel architecture (e.g., arm64), unpacks boot.fex, and patches the ramdisk using the hybrid Magisk engine (Native V4 / WebModern).

Detecta automáticamente la arquitectura del Kernel (ej. arm64), descomprime boot.fex y parcha el ramdisk utilizando el motor híbrido Magisk (Native V4 / WebModern).

03

Optional: Customize Logos

Opcional: Personalizar Logos

Inject custom bootlogo.bmp (1920x1080) and fastbootlogo.bmp (257x246). Fully optional step: skip directly to Step 4 if stock logos are desired.

Inyecta bootlogo.bmp (1920x1080) y fastbootlogo.bmp (257x246). Paso 100% opcional: si no deseas cambiar logos, pasas directo al Paso 4.

04

Repack Modified ROM (.img)

Reempaquetar ROM Modificada

Recompiles the final .img file, accurately recalculating all Allwinner verification checksums (V*.fex) without corrupting partition tables.

Recompila la imagen .img final recalculando con precisión todos los checksums de verificación de Allwinner (V*.fex) sin dañar la tabla de particiones.

05

Flash ROM to Device

Flashear ROM al Dispositivo

Directly initiates safe USB flashing (Full Erase + Flash + Verify + Reboot) to the connected device after confirming physical SoC compatibility.

Inicia el flasheo USB seguro (Full Erase + Flash + Verify + Reboot) hacia el dispositivo conectado tras verificar la compatibilidad física del SoC.

Hardware Flashing Safety Guidelines

Pautas de Seguridad para Flasheo de Hardware

Always use a reliable USB-A to USB-A cable, maintain steady power supply to your projector or SBC during flashing, and ensure you have physical access to the device's FEL recovery test points in case of power interruption.

Utiliza siempre un cable USB-A a USB-A de calidad con buena transferencia de datos, mantén una fuente de alimentación estable durante el flasheo y asegúrate de conocer los pines de prueba FEL del dispositivo ante cualquier eventualidad.

Allwinner H713 Smart Projectors

SoC ID 0x1860. Confirmed target on Magcubic L018, HY300, HY320 smart projectors running Android 11. Fully audited full-flash logo and Magisk rooting baseline.

SoC ID 0x1860. Objetivo confirmado en proyectores Magcubic L018, HY300, HY320 con Android 11. Base auditada para flasheo completo de logos y root con Magisk.

Allwinner H616 / H618 TV Boxes & SBCs

Quad-Core Cortex-A53 media platform powering OTT TV boxes (T95, Tanix TX6s, X96) and maker SBCs such as Orange Pi Zero 2 and Orange Pi Zero 3.

Plataforma multimedia Quad-Core Cortex-A53 para TV boxes OTT (T95, Tanix TX6s, X96) y placas maker como Orange Pi Zero 2 y Orange Pi Zero 3.

Allwinner H313 Budget OTT Media

Cost-effective Quad-Core processor for entry-level TV sticks and media players running Android 10/11 Go and AOSP lightweight distributions.

Procesador Quad-Core optimizado para sticks de TV y reproductores multimedia económicos con Android 10/11 Go y distribuciones ligeras AOSP.

Allwinner A523 / T527 Tablets & Industrial

Modern Octa-Core architectures utilized in contemporary commercial Android 12/13/14 tablets, interactive kiosks, and industrial embedded control boards.

Arquitecturas Octa-Core modernas utilizadas en tablets comerciales con Android 12/13/14, kioscos táctiles y placas de control industrial.
